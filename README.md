## ✦ About

**ALL IN** is an independent creative technology studio built around one simple idea:

> **Build things worth keeping.**

The studio brings software engineering, digital products, creative releases, and physical goods under one identity.

From full-stack platforms and developer tools to limited physical releases, every project is built with the same principles:

**clarity · utility · precision · identity**

---

### 01 — Software & Engineering

## ✦ The Philosophy

**ALL IN** is not built around one category.

It is built around a way of making.

We believe good work should be:

| Principle         | Meaning                                                                        |
| :---------------- | :----------------------------------------------------------------------------- |
| **Useful**        | Solve a real problem or create genuine value.                                  |
| **Intentional**   | Every feature, detail, and decision has a reason.                              |
| **Simple**        | Complexity should exist only when it serves a purpose.                         |
| **Built to Last** | Avoid disposable work. Build systems, products, and identities with longevity. |
| **Distinct**      | Function matters, but identity matters too.                                    |
